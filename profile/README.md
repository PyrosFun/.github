## More Projects

There's more here than Discord bots. PyrosFun is home to mods, utilities, experiments, infrastructure, and other software I've built over the years.

### 🎮 Game Mods & Plugins

**SuperCallouts**
A large collection of callouts for LSPDFR.

**SuperEvents**
Dynamic world events and scenarios for LSPDFR.

**DeadlyWeapons**
A realistic weapon damage overhaul for GTA V.

**Legendary Normal**
A Factorio mod for configurable item quality.

**Tiered Mechs**
Additional mechanitor progression for RimWorld.
